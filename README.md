# MediMater（配布版）

妊娠・出産・子育ての手続きと制度を、**いまの時期のぶんだけ**出すアプリです。

https://shogomedi4.github.io/

## このリポジトリにあるもの

書き出した1枚の HTML だけです。ソースコードは別の非公開リポジトリにあります。
`index.html` は `npm run export:web` と `python scripts/build-pages.py` の出力を
そのまま置いたものなので、ここを直接編集しないでください。次の書き出しで消えます。

## 中身について

- **監修前の下書きです。** 手続きの前に、必ず窓口か公式ページで確かめてください。
- 入力した予定日や住んでいる市区町村は、**その端末の中だけ**に残ります。
  サーバーには送りません。
- 検索には載らないようにしてあります（`noindex`）。監修が済んだら外します。
